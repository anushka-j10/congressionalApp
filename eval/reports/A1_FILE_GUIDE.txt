A1 file-by-file explanations

146 A1-created files are listed; original code changes are described in AI_USAGE.md.

DESIGN_NOTES.md
These editable notes explain the measurement definitions and the test corpus choices. They document the failed baseline threshold and keep extraction design behind the review gate.

eval/generate_reader_samples.py
This script creates clean copies and seven fixed degraded versions of every invented source page. It writes exact text pairs and a parameter manifest without changing the original M1 images or JSON.

eval/reader-corpus.json
This manifest records fixed image-effect parameters, seeds, font checksum, and clean source hashes. It identifies the exact reproducible corpus for later reader comparisons.

eval/reader_bakeoff.py
This script scores actual reader output using exact character edit distance and digit-sensitive key-token recall. It automatically discovers handwriting pairs and records unavailable readers as unmeasured.

eval/reports-a1-table.txt
This file contains the real console table from the baseline run. It is suitable for a screenshot and distinguishes tested rows from N/A rows.

eval/reports/A1_FILE_GUIDE.txt
This file inventories each A1-created source, data, and report file with two-sentence explanations. It complements the shorter source-file guide in the README.

eval/reports/reader-baseline-analysis.md
This report explains which degradation conditions failed and lists exact missed tokens. It separates next comparison options from evidence-backed reader selection.

eval/reports/reader-baseline.json
This report holds measured per-page metrics, target inventories, missed values, and production fingerprints. It records vision as not run and handwriting as absent instead of inventing scores.
